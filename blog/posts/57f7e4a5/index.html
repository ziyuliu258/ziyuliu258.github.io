论文阅读：FoundationPose

发表于2026-11-21|更新于2026-11-22
|总字数:5.2k|阅读时长:18分钟|浏览量:—

引：本文来自 NVIDIA (Bowen Wen, Wei Yang, Jan Kautz, Stan Birchfield)，CVPR 2024。它想用一个模型同时解决四件事：新物体的 6D 位姿估计与位姿跟踪，以及每条任务线下的基于模型（给 CAD）与无模型（给少量参考图）两种设定。它通过“渲染—比较”统一这些任务：只要能把物体渲染出来，四个任务就退化成同一个位姿优化加同一个打分问题。

图来自原论文 Figure 1：两条输入路线（参考图 / CAD 模型）分别通向位姿估计与位姿跟踪，右下角极坐标图是四个子任务上相对已有方法的比较。

背景

把物体位姿写成从物体坐标系到相机坐标系的刚体变换，这件事在工业界早就能做准，前提是训练时见过这个实例。这类 instance-level 方法要么用带纹理的 CAD 模型渲染训练数据，要么在测试实例上重新训练，代价是遇到没见过的物体就失效。

放宽一层是 category-level，允许测试时是新实例，但必须属于训练过的类别。再放宽就是本文关注的 novel object：测试时给一个从没见过的物体，只额外提供一点关于它的知识。这点知识有两种形态，也正是论文反复强调的两种设定：

  • 基于模型：给一个带纹理的 CAD 模型；
  • 无模型：给十几张（约 16 张）从不同视角拍摄的参考图。

已有的工作往往只做其中一条线。MegaPose 之类要求 CAD，Gen6D、OnePose 之类要求参考图并用 SfM 建模、靠 2D-3D 匹配解位姿；后者的通病是对无纹理物体和严重遮挡很脆弱，因为匹配本身没有东西可匹配。于是本文的问题变成：能不能让两种输入走同一条流水线，并且顺带把跟踪也吃掉。

作者的答案是：把两种输入都先变成“能渲染出 RGBD 的东西”。CAD 走传统图形管线，参考图走一个按物体优化的神经隐式场。之后的所有模块——位姿精化、位姿选择、跟踪——都只跟“渲染结果”打交道，不再关心输入从哪来。

方法

给定带纹理的 CAD，或者用多视角参考图拟合出网格，系统都能按候选位姿渲染物体。单帧估计从一批初始位姿出发，反复比较渲染结果与实拍，再从精化后的候选中选出最终位姿。

flowchart TD
    CAD["带纹理的 CAD"] --> Render["按候选位姿渲染 RGB-D"]
    Refs["多视角参考 RGB-D"] --> Mesh["拟合带纹理网格"] --> Render
    Init["初始位姿候选"] --> Render
    Render --> Compare["比较裁剪后的渲染与实拍"]
    Compare --> Refine["修正平移和旋转"]
    Refine -->|继续精化| Render
    Refine -->|精化完成| Rank["比较精化候选并排序"]
    Rank --> Pose["输出得分最高的位姿"]

跟踪沿用上一帧位姿作为初值，只走一轮精化。下文依次展开物体建模、位姿精化和候选排序。

图来自原论文 Figure 2：上半部分是语言辅助的合成数据生成；左中是神经物体建模；右中是位姿假设生成（全局采样 + 精化网络）；下半是位姿选择（分层比较 + 对比学习）。

数据从哪来

四个任务共用一套网络，泛化能力只能来自训练数据的覆盖度。真实数据既拿不到足够多物体，也标不准 6D 位姿，所以作者全部用合成数据：形状取自 Objaverse-LVIS（4 万余个物体，1156 个 LVIS 类别）与 GSO，场景在 Isaac Sim 里做物理仿真和路径追踪渲染。

难点在纹理。Objaverse 的形状质量不错，但纹理参差不齐；FS6D 的做法是把 ImageNet 或 COCO 的图片随机贴到 UV 上，结果是接缝和错位。本文改用两级提示词：先把“请描述一个〈thermos bottle〉可能的外观、颜色与风格”这样的模板里的类别标签填上，交给 LLM 生成一段描述，再把这段描述和随机初始化的噪声纹理一起喂给 TexFusion 做纹理合成。这样每个物体能用 3 到 5 个种子生成多种风格，且全自动。

图来自原论文 Figure 3：上排是 FS6D 的随机贴图，下排是本文用 LLM 生成描述再由扩散模型合成的纹理。

无模型时的物体表示

参考图给的是若干视角的 RGBD，要拿它渲染任意新视角，就得先有个三维表示。作者用一个以物体为中心的神经场，拆成两个函数：

  • 几何 Ω:x↦s\Omega:\mathbf{x}\mapsto sΩ:x↦s，输入三维点输出有符号距离 sss；
  • 外观 Φ:(fΩ(x),n,d)↦c\Phi:(f_\Omega(\mathbf{x}),\mathbf{n},\mathbf{d})\mapsto\mathbf{c}Φ:(fΩ​(x),n,d)↦c，输入几何网络的中间特征、法向与视线方向，输出颜色。

输入点先做多分辨率哈希编码再进网络（4 层，特征维 16 到 128，哈希表大小 2222^{22}222）。真正的曲面取零水平集 S={x∈R3∣Ω(x)=0}\mathcal{S}=\{\mathbf{x}\in\mathbb{R}^3\mid\Omega(\mathbf{x})=0\}S={x∈R3∣Ω(x)=0}。相比 NeRF 的密度场，SDF 的好处是深度渲染质量更高，而且不用手工挑密度阈值——这一点对后面要渲染深度图做比较至关重要。

为高效并行渲染大量位姿假设，作者先用 marching cubes 抽出零水平集网格并投影颜色，得到带纹理的 mesh，之后所有渲染都走光栅化。

位姿假设的生成

单帧位姿估计的第一步是撒初始假设。检测框由 Mask R-CNN 或 CNOS 给出，平移取框内深度中位数对应的三维点；旋转在物体中心的二十面球上均匀采 Ns=42N_s=42Ns​=42 个视点，每个再离散出 Ni=12N_i=12Ni​=12 个面内旋转，一共 504 个初始位姿。

这些初始位姿很粗，所以需要一个精化网络反复修正。它的输入是两幅 RGBD：在粗位姿下渲染出的物体图，以及从观测中裁出的一块。两个分支共享同一个 CNN 编码器，特征拼接后过残差卷积块，切成 patch、加位置编码，送进 transformer 编码器，最后分两路线性投影出平移更新 Δt∈R3\Delta\mathbf{t}\in\mathbb{R}^3Δt∈R3 与旋转更新 ΔR∈SO(3)\Delta\mathbf{R}\in SO(3)ΔR∈SO(3)（实际用轴角参数化，作者试过 6D 表示，效果相近）。

更新方式值得单独看：

t+=t+Δt,R+=ΔR⊗R,\mathbf{t}^{+}=\mathbf{t}+\Delta\mathbf{t},\qquad \mathbf{R}^{+}=\Delta\mathbf{R}\otimes\mathbf{R}, t+=t+Δt,R+=ΔR⊗R,

其中 ⊗\otimes⊗ 表示 SO(3)SO(3)SO(3) 上的复合。平移更新与旋转更新被解耦——更新 t\mathbf{t}t 时不依赖已经转过一次的姿态，两个更新都表达在相机坐标系里，于是输入观测和输出更新落在同一个坐标系中，学习起来更简单。训练用 L2 损失：

Lrefine=w1∥Δt−Δtˉ∥2+w2∥ΔR−ΔRˉ∥2,\mathcal{L}_{\text{refine}}=w_1\left\|\Delta\mathbf{t}-\Delta\bar{\mathbf{t}}\right\|_2+w_2\left\|\Delta\mathbf{R}-\Delta\bar{\mathbf{R}}\right\|_2, Lrefine​=w1​∥Δt−Δtˉ∥2​+w2​​ΔR−ΔRˉ​2​,

w1=w2=1w_1=w_2=1w1​=w2​=1。

裁剪方式也是专门设计的。通常做法是按 2D 检测框裁，但那样裁出的区域与位姿无关，网络收不到平移的反馈。这里改成位姿条件裁剪：把物体原点投影到图像上作为裁剪中心，把略微放大的物体直径（表面上任意两点间的最大距离）投影出的长度作为裁剪边长。这样一旦平移有偏差，裁出来的框就会偏，网络从“框对不齐”里就能读出该往哪边移。渲染图也按同一个位姿裁剪并缩放到 160×160160\times160160×160，两路输入在几何上对齐。

推理时位姿估计迭代 5 次，跟踪只迭代 1 次——跟踪有上一帧的位姿做初值，一次就够。

位姿选择

504 个假设各精化一遍之后，要挑出一个。位姿选择网络用分层比较：

第一层逐个假设做，把渲染图和裁剪后的观测一起送进位姿排序编码器（骨干与精化网络相同），特征拼接、token 化后过自注意力，平均池化得到 F∈R512F\in\mathbb{R}^{512}F∈R512，描述“这张渲染和观测有多贴合”。到这一步可以直接投影成一个相似度标量，但作者说这样不好学，因为网络被迫给每个假设打绝对分。

第二层把这些特征拼起来 F=[F0,…,FK−1]⊤∈RK×512F=[F_0,\dots,F_{K-1}]^{\top}\in\mathbb{R}^{K\times512}F=[F0​,…,FK−1​]⊤∈RK×512，再过一次多头自注意力，线性投影成 KKK 个分数。这一层不加位置编码，因为假设之间本来就是无序集合，分数不该依赖排序。

图来自原论文 Figure 4：上排是本文的分层比较，排序趋势与真实最优（红圈）一致；下排只做单假设比较，排序在形状与纹理之间摇摆。

训练用位姿条件三元组损失：

L(i+,i−)=max⁡(S(i−)−S(i+)+α, 0),\mathcal{L}(i^+,i^-)=\max\left(\mathbf{S}(i^-)-\mathbf{S}(i^+)+\alpha,\,0\right), L(i+,i−)=max(S(i−)−S(i+)+α,0),

α\alphaα 是要求正、负位姿假设之间达到的 最小得分间隔（margin）。用 ADD 指标对照真实位姿确定 i+i^+i+ 和 i−i^-i−。正样本得分比负样本至少高出 α\alphaα 时，这一对的损失才为零。这里的锚样本（anchor）是用来与渲染图比较的观测图像裁剪。正、负位姿假设各自决定裁剪区域，因此它们用到的观测裁剪也可能不同。

还有一处是为了让比较有意义：两个都离真值很远时谁好谁坏本就说不清，所以只保留正样本足够接近真值的那些对：

V+={i:D(Ri,Rˉ)<d},V−={0,1,…,K−1},\mathbb{V}^{+}=\left\{i: D(\mathbf{R}_i,\bar{\mathbf{R}})<d\right\},\qquad \mathbb{V}^{-}=\{0,1,\dots,K-1\}, V+={i:D(Ri​,Rˉ)<d},V−={0,1,…,K−1},

Lrank=∑i+,i−L(i+,i−),\mathcal{L}_{\text{rank}}=\sum_{i^{+},i^{-}}\mathcal{L}(i^{+},i^{-}), Lrank​=i+,i−∑​L(i+,i−),

其中 D(⋅)D(\cdot)D(⋅) 是旋转的测地距离，ddd 是预设阈值。作者也试过对比学习里常用的 InfoNCE，结果更差，原因是它默认平移已经对齐，而这里平移恰恰是待估的量。

跟踪与两种输入的统一

跟踪几乎不需要新结构：每个时刻，把当前帧的裁剪图和用上一帧位姿渲染出的图送进精化模块，输出就是当前位姿，沿视频序列重复即可。首帧位姿由单帧估计给出。

到这里，“统一”到底统一在哪就清楚了：基于模型 时渲染来自 OpenGL 与传统图形管线，无模型 时渲染来自神经物体场，两者都输出同一种 RGBD 图像，于是精化网络与选择网络只有一套，训练时还把两种渲染混在一起喂，让网络见过两种输入分布。

实验

数据集五个：LINEMOD、Occluded-LINEMOD、YCB-Video、T-LESS、YCBInEOAT，覆盖杂乱堆叠、多实例、静态与动态场景、桌面与机械臂操作，物体含无纹理、反光、对称、尺寸跨度大的情形。指标按各基准的惯例：ADD 与 ADD-S 的 AUC、ADD-0.1ddd 召回率、BOP 挑战的 AR（VSD、MSSD、MSPD 的平均）。

无模型的单帧估计在 YCB-Video 上，ADD-S 与 ADD 的 AUC 是 97.4 / 91.5，而 FS6D 是 88.4 / 42.1，PREDATOR、LoFTR 更低。在 LINEMOD 上按 ADD-0.1ddd 平均 99.9，FS6D 配合 ICP 是 91.5，LatentFusion 87.1，OnePose++ 76.9。这个对比里最要紧的一点是：本文不做任何微调，而 FS6D 需要在该数据集上微调，OnePose++ 需要 200 张参考图，本文只要 16 张。

基于模型的估计在 BOP 三个核心数据集上平均 AR 83.3 (LM-O 78.8, T-LESS 83.0, YCB-V 88.0)，对比 MegaPose-RGBD 的 58.6、GCPose 的 65.2 领先很多。作者提到当时在 BOP leaderboard 上比此前最好成绩还高 0.03 AR。

跟踪在 YCBInEOAT 上 ADD 93.09、ADD-S 96.42；对手里 se(3)-TrackNet 是 92.66 / 95.53，而它是逐实例训练的，本文是即时可用。在 YCB-Video 的跟踪上平均 ADD 96.0、ADD-S 97.9。还有一项能力是别人没有的：把位姿估计当作初始化，就能做端到端的估计加跟踪，不需要外部给首帧位姿（表中记为 Ours†）。

消融（YCB-Video 上的 ADD / ADD-S AUC）里，去掉 LLM 纹理增强是 90.83 / 97.38，把 transformer 换成卷积加线性层是 90.77 / 97.33，去掉分层比较是 89.05 / 96.67，换成 InfoNCE 是 89.39 / 97.29，完整模型 91.52 / 97.40。四项里分层比较的影响最大，这也和它的设计动机一致。

两条规模曲线也值得记：参考图数量在 12 张左右饱和，但只用 4 张时仍然强过用 16 张的 FS6D；训练数据量在约 100 万张图像处饱和，而整套训练在 4 张 V100 上花了一周。

运行时间 (RTX 3090)：单帧位姿估计约 1.3 s，其中初始化 4 ms、精化 0.88 s、选择 0.42 s；跟踪约 32 Hz。实际用法是估计一次做初始化，之后切到跟踪模式。

核心点和不足

值得关注

这篇的真正贡献不在某个网络模块，而在把四个任务压成同一个“渲染—比较”循环。一旦承认“位姿好坏等价于渲染与观测的贴合程度”，基于模型与无模型的差别就只剩渲染器；估计与跟踪的差别就只剩用不用上一帧做初值。这个抽象让一套网络覆盖四种设定，也让训练数据可以混着用。

第二个值得记的是位姿条件裁剪。它看起来只是数据预处理的小改动，实际上是把“平移误差”变成网络可见的信号：框不对齐，网络就知道该往哪移。很多 render-and-compare 方法在这里丢掉的信息，比在网络结构上做文章的收益更大。

第三个是分层比较。单假设打分是绝对判断，容易在形状对但纹理差、或纹理对但形状偏之间摇摆；把全部假设放进一个自注意力里，网络看到的是这一批候选的相对关系，排序趋势更稳。消融里它掉得最多，也印证了这一点。

仍然存在的问题

无模型设定并没有真的摆脱物体相关的准备。 参考图仍要 16 张、要覆盖足够视角，神经场还要按物体优化一次（虽然只要几秒）。与“给一张图就能用”相比，门槛只是降低而不是消失；论文也承认参考图数量在 12 张处饱和——这个饱和点本身就说明视角覆盖有下限。

1.3 秒的单帧估计对闭环操作偏慢。 作者给的用法是估计一次再切跟踪，但真实抓取里物体被抓起来、被遮挡、被放下，位姿会失效，需要重新估计；论文没有报告重初始化频率对任务成功率的影响，也没有在真实机器人任务上做端到端评测，评测全是离线数据集。

遮挡与对称性仍是短板。 方法依赖渲染图与观测的像素级贴合，物体被大面积遮挡时，可见部分能对上很多位姿，选择网络要靠形状先验去猜。对称物体（圆柱、方形盒）本身就有多解，ADD 对对称物体不友好，论文用 ADD-S 缓解，但这是指标层面的规避，不是方法层面的解决。

合成数据的偏差没有量化。 训练数据全部来自 Objaverse 与 Isaac Sim，虽然做了纹理增强与材质、光照随机化，但从合成到真实的差距只能用最终指标间接反映。消融里 LLM 纹理增强只带来 0.7 个点（90.83 → 91.52），说明这个增强的有效性比论文叙述的语气要弱。

作者将超出单个刚性物体的状态估计列为未来工作。

总结

把流程按依赖顺序串一遍：

  • 用 LLM 生成纹理描述、再由扩散模型合成纹理，在 Isaac Sim 里批量生成带真值位姿的合成数据；
  • CAD 直接用图形管线渲染，无模型时用按物体优化的 SDF 神经场（几何 Ω\OmegaΩ + 外观 Φ\PhiΦ）建出可渲染的 mesh；
  • 在二十面球上采 504 个初始位姿，用共享骨干的精化网络迭代修正平移与旋转，裁剪范围跟着位姿走；
  • 用两级注意力给全部假设打分排序，训练时用位姿条件三元组损失，只保留正样本足够接近真值的对；
  • 把上一帧位姿的渲染当成输入，同一个精化模块就变成了跟踪器。

它给出的方法论启示是：当“好坏”可以被渲染出来比较时，位姿估计就退化成排序问题，而排序问题可以用对比学习在合成数据上大规模训练。这条路之所以成立，靠的是 SDF 神经场提供了足够快的、能出深度的渲染器。

顺着这条线值得再看的是两件事：一是把这个循环用到可形变物体与多物体联合位姿上（作者自己列为未来工作），二是把渲染—比较的自监督信号用到真实场景的在线自适应，减少对合成数据分布的依赖。
