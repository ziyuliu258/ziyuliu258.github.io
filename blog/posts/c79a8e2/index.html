论文阅读：3D Gaussian Splatting for Real-Time Radiance Field Rendering

发表于2026-11-15|更新于2026-11-15
|总字数:3.5k|阅读时长:11分钟|浏览量:—

引：3D Gaussian Splatting（3DGS）用一组可以优化位置、形状、透明度和颜色的三维高斯表示场景，再将它们投影到屏幕上进行快速混合。论文把表示、增密策略和光栅化一起设计，让场景能够从照片中重建，也能够实时渲染新视角。

背景

给定一个静态场景的多张照片以及拍摄这些照片的相机参数，新视角合成希望生成从其他位置看到的图像。NeRF 将场景表示成连续的辐射场：沿每条相机射线采样，得到不同位置的密度与颜色，再把它们累积成像素颜色。这样可以表达复杂的外观，但对许多射线和采样点求值会带来计算开销。后续方法通过网格、哈希编码等加速，但表示与采样方式仍影响质量和速度。

3DGS 选择一组显式的三维高斯作为场景元素。我们可以把每个高斯想象成一个有方向、有大小的模糊椭球：它有三维位置，也有随观察方向变化的颜色和透明度。渲染时不必沿每条射线逐点查询整个场，而是把这些椭球投影到图像上，只处理会影响画面的元素。

论文的三个关键设计是：可微的各向异性高斯表示、与参数优化交替进行的自适应增密，以及按 tile 排序和混合的快速光栅化。它们共同决定了最终的质量和速度。

方法总览

图来自原论文 Fig. 2：从 SfM 点云初始化高斯，交替优化参数与控制密度，通过可微光栅化计算图像误差。

输入是场景的照片和相机。作者使用 SfM 标定相机，同时得到稀疏点云；每个初始点都生成一个高斯。训练时随机选择一个已知相机，把当前高斯投影并渲染成图像，再和该相机拍摄的照片比较，反向传播更新高斯参数。期间还会复制、拆分或删除高斯，让表示容量适应场景。

这里的“训练”是 针对单个场景优化其高斯参数，而不是训练一个见到新场景后就能直接输出高斯的通用前馈网络。优化完成后，选择一个新的相机，就可以渲染该场景的新视角。

可微的高斯表示

三维高斯

每个高斯包含中心位置 μ\muμ、协方差矩阵 Σ\SigmaΣ、不透明度，以及表示颜色的球谐函数（Spherical Harmonics，SH）系数。以高斯中心为原点的相对位置 xxx，论文写出未归一化的高斯函数：

G(x)=e−12xTΣ−1xG(x)=e^{-\frac{1}{2}x^T\Sigma^{-1}x} G(x)=e−21​xTΣ−1x

对于一般的世界坐标，先令 xxx 等于该点与中心 μ\muμ 的差。离中心越远，权重通常越小；Σ\SigmaΣ 则控制不同方向上的衰减速度。若三个方向的尺度不同，高斯可以沿一个方向拉长、沿另一个方向压扁，因此比固定大小的圆点更容易贴合细长或平坦的结构。

高斯还要表达外观。SH 系数用于根据观察方向计算颜色，所以同一个高斯从不同方向看可以有不同颜色；不透明度控制它对最终像素的贡献。SH 提供的是有限阶的方向相关外观，并不直接赋予高斯精确的材质或表面法向。

直接更新协方差矩阵有个问题：任意梯度更新可能让它不再是有效的半正定矩阵。作者将其拆成缩放矩阵 SSS 与旋转矩阵 RRR：

Σ=RSSTRT\Sigma=RSS^TR^T Σ=RSSTRT

实际优化三维缩放向量 sss 和旋转四元数 qqq，由它们构造 SSS 和 RRR。四元数归一化后给出旋转，尺度通过指数激活保持为正；这样构造出的协方差满足所需约束。可以把 SSS 理解为先在三个轴上拉伸，再由 RRR 把椭球转到所需方向。

投影与混合

渲染一张图像时，需要将三维高斯投影成屏幕上的二维椭圆。论文使用投影在高斯中心附近的仿射近似，若 WWW 表示观察变换、JJJ 为投影变换的 Jacobian，投影后的协方差为：

Σ′=JWΣWTJT\Sigma'=JW\Sigma W^TJ^T Σ′=JWΣWTJT

取其中对应图像平面的二维部分，得到屏幕上的椭圆形高斯。透视投影本身是非线性的，因此这是局部近似；相机附近或屏幕上很大的高斯更容易暴露近似带来的问题。

假设一个像素被若干高斯覆盖，按从近到远排列后，其颜色由 alpha blending 计算：

C=∑i∈Nciαi∏j=1i−1(1−αj)C=\sum_{i\in N}c_i\alpha_i\prod_{j=1}^{i-1}(1-\alpha_j) C=i∈N∑​ci​αi​j=1∏i−1​(1−αj​)

其中 cic_ici​ 是第 iii 个高斯沿观察方向计算出的颜色，αi\alpha_iαi​ 是其不透明度乘以该像素位置处的二维高斯权重。前面高斯的 ∏j<i(1−αj)\prod_{j<i}(1-\alpha_j)∏j<i​(1−αj​) 表示光透过它们后剩下的比例。例如前面一个高斯在该像素的不透明度为 0.8，后面一个高斯的贡献就只剩原来的 0.2 倍。论文指出，这种累积形式与离散体渲染相似，但这里通过投影和光栅化找到贡献元素，而不是在每条射线上密集采样。

优化与自适应密度控制

参数优化

SfM 点云通常稀疏且没有法向。作者用每个点初始化一个各向同性高斯，其初始尺度取邻近三个点距离的平均值；随后优化中心、缩放、旋转、不透明度和 SH 系数。渲染结果与训练图像之间的目标为：

L=(1−λ)L1+λLD−SSIM,λ=0.2\mathcal{L}=(1-\lambda)\mathcal{L}_1+\lambda\mathcal{L}_{\mathrm{D-SSIM}},\qquad \lambda=0.2 L=(1−λ)L1​+λLD−SSIM​,λ=0.2

L1\mathcal{L}_1L1​ 比较像素颜色，D-SSIM 项衡量局部结构差异。因为投影、混合与颜色计算支持反向传播，图像误差可以更新参与渲染的高斯。作者还逐步增加 SH 的阶数，避免观测角度不足时高阶方向相关项过早吸收本应由基础颜色解释的误差。

但是只调整初始高斯的参数不够：稀疏点云可能漏掉结构，一个大高斯也可能同时覆盖形状不同的区域。所以优化过程中还需要改变高斯的数量与分布。

增密与删除

图来自原论文 Fig. 4：覆盖不足时复制小高斯，较大的高斯难以表示细节时将其拆分。

作者用 视空间位置梯度的平均大小 寻找需要增密的高斯：梯度大说明图像误差对其屏幕位置比较敏感，是需要进一步调整的线索。它只是启发式信号，并不能单独证明真实几何一定缺失。

  • 对尺寸较小、覆盖不足的高斯， clone 一个同尺寸副本，让后续位置优化把它们分开，以覆盖更多区域。
  • 对尺寸较大、覆盖范围内存在细节的高斯， split 成两个更小的高斯，新中心从原高斯对应的分布采样，尺度除以 1.6，再继续优化。
  • 对透明度过低的高斯进行删除；过大的高斯也会被清理。作者周期性地将透明度重置到接近零，使有用的高斯重新获得透明度，并让无用高斯更容易被删去。

增密从优化预热后开始，每 100 次迭代执行一次；论文使用的位置梯度阈值为 0.0002，透明度重置间隔为 3000 次。这里的密度控制是调整 高斯元素的数量和空间分布，不是 NeRF 中射线采样位置的体密度 σ\sigmaσ。

快速可微光栅化

如果每个像素分别找出所有覆盖它的高斯、再单独排序，代价会很高。作者将屏幕划分为 16×1616\times1616×16 的 tile，并在 GPU 上按 tile 批量处理：

  1. 将高斯投影到屏幕，剔除视锥外或明显不参与渲染的元素；
  2. 对每个高斯涉及的 tile 生成对应条目，以 tile ID 和视空间深度组成排序键，通过 GPU radix sort 一次排序；
  3. 每个 tile 得到一段按深度排列的高斯列表，由一个线程块共同加载数据；每个像素沿列表从前往后混合颜色，累积不透明度接近饱和时提前停止；
  4. 反向传播再次遍历排序列表，恢复混合所需的中间量，把梯度传回参与贡献的高斯。

注意，这里 排序是 tile 级的，并没有对每个像素重新排序。因此大高斯相互交叠时，近似的可见性顺序可能和逐像素的精确顺序不同；换来的是较高吞吐量。作者也没有预先设定一个固定的“最多多少个高斯接收梯度”的截断数量，而是根据实际混合和不透明度饱和停止。

实验

设置与指标

消融

论文 Table 3 在 Truck、Garden、Bicycle 三个场景上检查不同设计。30K 次迭代时，完整方法的平均 PSNR 是 26.05；去掉 split 为 23.90，改用各向同性高斯为 25.23，去掉 SH 为 25.35。分别去掉 clone 或 split 的结果并不相同：两者处理的尺度与覆盖问题不同，也不能仅凭平均数推断某个场景中的每一处误差来源。

作者还比较了随机初始化和 SfM 初始化，以及限制反向传播的高斯数量。论文报告随机初始化尤其在大场景中较难优化；限制接收梯度的前方高斯数量会显著影响复杂遮挡场景。它们说明初始几何与可微渲染的实现都参与了最终质量。

核心点和不足

3DGS 的关键是把场景表示和渲染过程放在一起考虑。高斯的各向异性让一个元素可以覆盖有方向的局部结构；自适应增密把更多元素分配给难以拟合的区域；tile 光栅化则让这组显式元素可以高效地投影、排序和混合。图像误差贯穿整个过程，决定高斯最后怎样分布。

这些高斯的首要目标是解释观察到的图像，而不是保证恢复准确、连续的物体表面。观测不足区域可能出现漂浮、拉长或斑块状伪影；视角变化时，较大高斯的剔除和近似深度排序也可能造成突然跳变。逐场景优化需要多张有足够覆盖的图像和可靠相机，模型存储还可能达到数百 MB。论文评估的是静态场景的新视角合成，并不能直接推出它能分离独立物体或重建未观测到的完整几何。

总结

3DGS 的流程可以概括为：从 SfM 点云初始化高斯，利用训练照片优化高斯及其密度，再通过按 tile 排序的可微光栅化渲染。它将体渲染中沿射线累积颜色的思路与显式、可增删的空间元素结合起来，在论文的测试场景中同时获得较好的新视角质量和实时渲染速度。

与 VGGT 联系起来看，VGGT 从图像直接预测相机和稠密几何，3DGS 则在相机与初始化几何的基础上拟合一个可渲染的外观表示。若用前者输出初始化后者，还要处理坐标系、尺度、相机精度和点云筛选，并继续优化高斯；这是一条可以探索的组合路线，不是两篇原论文已经验证的完整管线。
