论文阅读：Point Transformer V3

发表于2026-11-25|更新于2026-11-25
|总字数:3.9k|阅读时长:14分钟|浏览量:—

引：Point Transformer V3（PTv3）由香港大学（Xiaoyang Wu、Hengshuang Zhao 等）、上海人工智能实验室、港中深、北大与 MIT 联合提出（CVPR 2024 Oral）。这篇论文最反直觉的地方在于：它并没有在注意力公式里发明更花哨的几何算子，而是主动放弃了点云架构长期执着的“精确 KNN 邻域 + 复杂相对位置编码”，用空间填充曲线序列化换取极简的计算流。结果把 PTv2 中占去 54% 前向时间的瓶颈彻底砍掉，在单卡上实现 3.3× 推理加速与 10.2× 显存下降，并将注意力感受野从 16 个点一口气扩到 1024 个点。

图来自原论文 Figure 1：PTv3 与 PTv2 及主流三维主干在精度、感受野（16 → 1024 点）、推理延迟（3.3× 加速）与显存占用（10.2× 降低）上的全面对比。

背景与设计原则

在二维视觉和自然语言处理领域，模型性能的跃升很大程度上来自 Scaling Principle（规模化原则）——扩大数据集规模、增加参数与通道数、拉大有效感受野并投入更多算力。但在三维点云领域，主干网络却长期被“精度–效率权衡”锁死了上限：

  • 稀疏卷积（如 MinkUNet）速度快、省显存：借助多数据集联合训练（PPT (Wu et al., 2024b)），MinkUNet 在 ScanNet 上的语义分割 mIoU 从 72.2% 涨到 77.0%，甚至反超了从头训练的 PTv2；但卷积核形状固定，很难像注意力那样灵活扩大感受野。
  • 点云 Transformer（PTv1 / PTv2、Stratified Transformer、Swin3D）感受野潜质大，却慢得扩不动：为了严格满足点云的置换不变性（permutation invariance），PTv2 必须用 K 近邻（KNN） 动态构建局部邻域，并用点对欧氏距离计算相对位置编码（RPE）。作者对 PTv2 的前向耗时做了细粒度剖析：KNN 查询占了 28%，RPE 占了 26%，两者合计吃掉了一半以上（54%）的计算时间！

图来自原论文 Figure 2：PTv2 前向推理各模块耗时占比，KNN Query（28%）与 RPE（26%）合计占据 54% 的前向时间。

看到这组数据后，作者提出了一个非常干脆的判断：模型性能更多由规模决定，而非局部模块的精巧复杂度。与其死守“无序点集 + 精确局部几何”而付出高昂的工程代价，不如借鉴 OctFormer (Wang, 2023) 和 FlatFormer (Liu et al., 2023) 的思路，主动打破置换不变性，把无序点云序列化为结构化序列。只要计算足够简单高速，就能把感受野和训练数据规模拉上去，用“规模红利”轻松盖过局部邻域近似带来的微小损失。

方法：Point Transformer V3

PTv3 的整体流程非常克制：先通过空间填充曲线把无序点云编码成一维有序索引，再在结构化序列上运行带有前置稀疏卷积位置编码（xCPE）的块内点积注意力，最后嵌回标准的四阶段 U-Net 架构中。数据流如下图所示：

flowchart TD

    SER --> MAP["记录 4 种序列化索引映射（Z / Trans-Z / Hilbert / Trans-Hilbert）"]
    MAP --> ENC["4 阶段 U-Net 编码器（深度 [2, 2, 6, 2]）"]
    ENC -->|Grid Pooling + Shuffle Order| ENC
    ENC -->|跳跃连接 + 上采样| DEC["4 阶段 U-Net 解码器（深度 [1, 1, 1, 1]）"]
    subgraph BLK["PTv3 基础块（Pre-Norm + LN）"]
        XCPE["xCPE：前置 SparseConv + 残差跳连"] --> LN1["LayerNorm"]
        LN1 --> PA["Serialized Patch Attention（Patch Size = 1024，FlashAttention）"]
        PA --> LN2["LayerNorm + MLP"]
    end

点云序列化

为了把三维点云压成一维序列同时尽量保留空间邻近性，PTv3 采用空间填充曲线（space-filling curves）——一种将高维离散网格双射到一维整数序列的函数 φ:Z↦Zn\varphi: \mathbb{Z} \mapsto \mathbb{Z}^nφ:Z↦Zn（此处 n=3n=3n=3）。作者选取了两种经典曲线及其轴序转置变体，共 4 种序列化模式：

  • Z-order 曲线（Morton 码）：把 (x,y,z)(x,y,z)(x,y,z) 的二进制坐标位交错拼接，计算极快；
  • Hilbert 曲线：局部连续性保持得比 Z-order 更好，相邻点在曲线上更少出现长距离跳跃；
  • Trans Z-order 与 Trans Hilbert：将坐标轴遍历优先级从 (x,y,z)(x,y,z)(x,y,z) 改为优先 yyy 轴等转置顺序，从另一视角捕捉标准曲线可能切断的局部邻接关系。

图来自原论文 Figure 3：四种序列化模式的三联图展示——每组从左到右分别为空间填充曲线路径、按曲线排序后的点云序列，以及切分后的局部注意力 patch。

给定离散网格尺寸 g∈Rg\in\mathbb{R}g∈R、点坐标 pi∈R3\bm{p}_i\in\mathbb{R}^3pi​∈R3 和所属批次索引 b∈Zb\in\mathbb{Z}b∈Z，每个点都会被映射为一个 64 位整数序列化编码：

Encode(p,b,g)=(b≪k)|φ−1(⌊p/g⌋)\texttt{Encode}(\bm{p}, b, g) = (b \ll k) \texttt{|} \varphi^{-1}(\lfloor \bm{p} / g \rfloor) Encode(p,b,g)=(b≪k)|φ−1(⌊p/g⌋)

  • p\bm{p}p：输入点的三维连续坐标；
  • ggg：网格离散化步长（grid size），⌊p/g⌋\lfloor \bm{p}/g \rfloor⌊p/g⌋ 将点映射到三维整数网格；
  • φ−1:Z3↦Z\varphi^{-1}: \mathbb{Z}^3 \mapsto \mathbb{Z}φ−1:Z3↦Z：空间填充曲线的逆映射，输出该网格单元在曲线上的一维整数序号；
  • kkk：为空间编码预留的低位比特数；
  • b≪kb \ll kb≪k 与 |\texttt{|}|：将批次索引左移 kkk 位后与空间编码做按位或，保证按编码排序时不同 batch 的点不会混在一起。

工程上有一个很巧妙的细节：PTv3 并不真正去物理重排点云张量，而只是记录四种模式各自的排序索引映射。这样在网络不同层之间切换序列化模式时，只需要做一次轻量索引 gather，几乎零额外开销。

序列化注意力

把点云拉成有序序列后，PTv3 彻底抛弃了 PTv2 中耗时的“KNN 邻域 + 向量注意力”，回归到图像 Transformer 里已经高度硬件优化的窗口点积注意力（可直接调用 FlashAttention）。围绕序列化序列，作者做了三项关键设计：

  1. Patch Grouping（序列分组与借位填充）：沿着当前序列化顺序，把点云直接切分成互不重叠、固定长度为 SSS（如 1024）的 patch。如果最后一个 patch 点数不够，就向相邻 patch “借用”点来补齐（padding），实现上重排与补齐可以合并成一次索引操作。

图来自原论文 Figure 4：(a) 按选定序列化顺序重排点云；(b) 从相邻 patch 借用点进行填充，使序列长度整除指定的 patch size。

  1. Patch Interaction（用 Shuffle Order 替代移位窗口）：如果每一层都用同一条曲线切 patch，跨 patch 的信息就永远无法交流。图像里常用 Shift Window，但移位窗口需要构造复杂的注意力掩码，会阻碍 FlashAttention 等算子融合。PTv3 对比了 Shift Dilation、Shift Patch、Shift Order（层间轮换曲线）和本文提出的 Shuffle Order（在层间随机打乱四种序列化模式的顺序）。实验证明，Shuffle Order 不需要任何注意力掩码，就能以零额外延迟实现最好的跨 patch 信息融合。

图来自原论文 Figure 5：五种 Patch 交互方式对比，其中 PTv3 主推的 Shuffle Order 通过随机打乱四种序列化曲线的层间顺序，在不引入注意力掩码的前提下打通跨块交互。

  1. xCPE（增强条件位置编码）：既然砍掉了占 26% 耗时的 RPE，位置信息怎么补？作者指出，点云里的 RPE 本质上等价于一种大核稀疏卷积；而前置条件位置编码（CPE）（即在注意力之前做一次局部卷积）正好能替代它。但单用普通 CPE 相比加了 RPE 仍有约 0.5% 的精度差距，于是 PTv3 提出 xCPE——在每个注意力层之前直接前置一层带残差跳连的稀疏 3D 卷积。由于它发生在注意力算子外部，既完全兼容 FlashAttention，又只带来几毫秒的开销。

网络宏观细节

在宏观架构上，PTv3 沿用标准的四阶段 U-Net 框架：编码器各阶段块深度为 [2, 2, 6, 2]，解码器为 [1, 1, 1, 1]，下采样网格尺寸按 [×2, ×2, ×2, ×2] 逐级倍增。

图来自原论文 Figure 6：PTv3 的整体 U-Net 架构与基础块内部结构，包含序列化、Grid Pooling、Shuffle Order 以及 Pre-Norm 块内的 xCPE 与点积注意力。

基础块内部也做了极简化调整：采用 Pre-Norm + LayerNorm（LN） 替代复杂的归一化堆叠，把 xCPE 紧贴放在注意力层前面；而在阶段间的 Grid Pooling 下采样层中，实验发现 BatchNorm（BN） 对稳定点云分布依然不可或缺，因此池化层保留 BN，并把 Shuffle Order 集成在池化阶段。

实验

效率与感受野扩展

在单张 RTX 4090（batch size = 1）上的基准测试直观兑现了“Simpler, Faster”的目标：

  • 室外 nuScenes（Tab. 1）：PTv2（patch size 16）推理耗时 146 ms、显存 12.3 G；而 PTv3 将 patch size 扩大 64 倍至 1024 后，推理耗时反而降至 44 ms（3.3× 加速），显存降至 1.2 G（10.2× 降低），甚至比稀疏卷积 MinkUNet/3（48 ms / 1.7 G）还要快且省显存。即使 patch size 进一步扩到 4096，延迟也仅微增至 45 ms。
  • 室内 ScanNet（Tab. 11）：PTv3 推理仅需 61 ms / 5.2 G，大幅领先 PTv2（191 ms / 18.2 G）、OctFormer（86 ms / 12.5 G）和 Swin3D（456 ms / 8.8 G）。

消融实验

在 ScanNet 语义分割验证集上的消融结果（默认配置均标为最优）逐一验证了第 4 节的设计取舍：

  1. 序列化模式与交互（Tab. 2）：仅用 Z-order + Shift Order 为 74.3 mIoU（54 ms）；加入转置曲线与 Hilbert 曲线（Z + TZ + H + TH）并配合 Shuffle Order 后，精度升至 77.3 mIoU，延迟仅 61 ms（而 Shift Dilation 和 Shift Patch 因需要注意力掩码，延迟飙到 99 ms 和 97 ms）。
  2. 位置编码（Tab. 3）：APE 仅 72.1 mIoU（50 ms），RPE 为 75.9（72 ms），cRPE 为 76.8（101 ms），CPE 为 76.6（58 ms），而 xCPE 达到 77.3 mIoU（61 ms），以极小代价拿到最高精度。
  3. 感受野（Patch Size）扩展（Tab. 4）：随着 patch size 从 16 → 32 → 64 → 128 → 256 → 1024 逐步放大，ScanNet mIoU 从 75.0 稳步攀升至 77.3（4096 时略微饱和至 77.1）。

下游任务表现

依托高效率与多数据集联合训练（PPT），PTv3 横扫了室内外 20 余项三维感知基准：

  • 室内语义分割（Tab. 5, 6）：从头训练即在 ScanNet 测试集达到 77.9 mIoU（超 PTv2 3.7%）、ScanNet200 测试集 37.8、S3DIS 6-fold 77.7；加入 PPT 联合训练后进一步升至 ScanNet 79.4、ScanNet200 39.3、S3DIS 6-fold 80.8。
  • 室外语义分割与目标检测（Tab. 7, 10）：nuScenes 联合训练达到 83.0 mIoU（test）、SemanticKITTI 75.5；在 Waymo 3D 目标检测上搭配 CenterPoint，单帧 Mean L2 mAPH 达到 70.5，超越 FlatFormer 3.3 个点。
  • 室内实例分割与数据效率（Tab. 8, 9）：固定 PointGroup 框架仅替换主干，PTv3 在 ScanNet 上拿到 40.9 mAP（结合 PPT 达 42.1 mAP，超 MinkUNet 6.1 个点）；在 ScanNet 仅 1% 重建场景或 20 个标注点的极低数据设置下依然大幅领先。

核心价值与不足

PTv3 最大的贡献在于给三维点云主干确立了一条清晰的工程与建模范式：在算力和数据规模成为主旋律的阶段，为了守住“置换不变性”而在 KNN 和 RPE 上付出 50% 以上的算力税是不划算的。用空间填充曲线换取规则的 1D 序列后，点云 Transformer 终于能直接享受 FlashAttention 和大感受野（1024 点）的红利。

同时，作者也在讨论中指出了两点局限，以及一个对后续工作很有启发的问题：

  • 点积注意力的收敛与深度瓶颈：为了效率从向量注意力退回到点积注意力后，深层网络会出现类似 NLP 中的 attention sink 现象，收敛速度与继续堆深的能力略弱于向量注意力。
  • 纯曲线序列化的局部边界问题：虽然加大 patch size 和 Shuffle Order 在语义分割上弥补了 KNN 的缺失，但空间填充曲线在象限边界处仍会把三维紧邻点打散（例如后来 SpaCeFormer 就明确指出了 PTv3 的这一不足，并在高分辨率层重新引入了固定几何尺度的空间窗口注意力来保住开放词汇实例分割的锐利边界）。

总结

PTv3 用三步极简改造完成了“Simpler, Faster, Stronger”的闭环：

  1. 打破置换不变性：用 Z-order / Hilbert 及其转置共四种空间填充曲线做轻量索引序列化，彻底告别 KNN；
  2. 拥抱硬件友好算子：用无掩码的 Shuffle Order + 大尺度 Patch Dot-Product Attention 替代移位窗口与向量注意力，直连 FlashAttention；
  3. 前置卷积补位置：用 xCPE（前置带跳连的稀疏 3D 卷积）替代高耗时的 RPE。

如果从阅读脉络往下接，PTv3 非常适合作为理解现代 3D 点云基础模型（如 Sonata、PPT）以及后续改进其局部几何连贯性的工作（如 SpaCeFormer）的基石来读。
