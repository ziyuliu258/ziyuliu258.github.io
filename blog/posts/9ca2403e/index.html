论文阅读：ScenePlacer

发表于2026-11-21|更新于2026-11-21
|总字数:4.2k|阅读时长:14分钟|浏览量:—

引：本文由香港科技大学、深圳 Loop Area Institute、香港大学与清华的研究者完成。它处理的是“把生成出来的物体放回场景”这一步：给定一张 RGB 图、由重建得到的部分点云，以及生成模型给出的完整 mesh，把物体摆回它在世界坐标里的位置和朝向。作者没有改生成器，也没有位姿回归头，而是把这件事重构成 在 mesh 上预测哪一片表面被看见，再用点云对齐求出变换。

图来自原论文 Figure 1：从输入图像出发，给定生成的物体与估计几何，估计它在场景中的位姿。

背景

组合式三维场景生成的一般流程是：从图像估计几何，逐个生成物体，再把物体摆回场景。前两步这几年进步很快，第三步却一直是短板。作者把现有做法归成两类，各自都有硬伤。

一类是在场景里直接生成。要么把所有物体放进一个共享的规范空间一起生成，受限于分辨率，形状质量下降；要么把观测到的部分点云当作条件，逐个物体生成。问题在于观测点云既不完整、朝向又随相机变化，等于要求生成模型在任意平移旋转下输出物体，而这违背了三维生成模型的基本假设—— 物体应当以原点为中心、与坐标轴对齐。

另一类是保持规范空间，另加一个位姿预测头，直接回归从物体坐标到世界坐标的平移、旋转、尺度。生成质量保住了，位姿精度却成了新的瓶颈：变换矩阵里一点点扰动，作用到几何上就是明显的偏移，回归本身是个病态问题。

更麻烦的是，这里的位姿估计和常规六自由度位姿不是一回事。生成出来的物体可能只是结构或功能上像被观测的物体，并没有忠实复现它的可见几何，所以基于对应点的刚体配准并不可靠；而且生成的物体通常被归一化到 [−1,1]3[-1,1]^{3}[−1,1]3，不带场景尺度，这又引入了尺度歧义，让基于渲染的位姿优化难以约束。Any6D 用多阶段的位姿与尺度精修来处理，但它依赖生成物与观测在几何上足够接近，误差还会在各阶段之间累积。

作者的判断是：与其在“生成质量”和“位姿精度”之间反复折中，不如把“摆放”当成一个独立问题来解。

方法

给定观测到的部分点云 PobsP_{\text{obs}}Pobs​ 与对应的生成网格 MgenM_{\text{gen}}Mgen​，目标是恢复两者之间的刚体变换。作者的切入点是：位姿可以由“哪一片表面被看见”唯一确定。如果能在物体的规范空间里找到与观测对应的那片可见表面，剩下的就只是点集配准。

图来自原论文 Figure 2：上排是场景生成流水线，下排左侧是训练数据构造，右侧是可见性场预测器（冻结的形状编码器 + 可训练的观测编码器）。

可见性场

把配准问题重新写成一个场的学习问题。网络 F\mathcal{F}F 接收网格与观测，对任意查询点 x∈R3x\in\mathbb{R}^{3}x∈R3 输出“它是否位于从该观测视角可见的表面上”的概率：

F(M,Pobs):R3→[0,1],V^(x)=F(M,Pobs)(x).\mathcal{F}\left(M,P_{\text{obs}}\right):\mathbb{R}^{3}\to[0,1],\qquad \hat{V}(x)=\mathcal{F}\left(M,P_{\text{obs}}\right)(x). F(M,Pobs​):R3→[0,1],V^(x)=F(M,Pobs​)(x).

把 V^(x)>τ\hat{V}(x)>\tauV^(x)>τ 的点收集起来，就得到与观测对齐的可见表面 PalignedP_{\text{aligned}}Paligned​；再解一个配准：

T∗=arg⁡min⁡T CD(T(Paligned),Pobs),T^{*}=\arg\min_{T}\ \mathrm{CD}\left(T\left(P_{\text{aligned}}\right),P_{\text{obs}}\right), T∗=argTmin​ CD(T(Paligned​),Pobs​),

TTT 是刚体变换，CD\mathrm{CD}CD 是两组点之间的 Chamfer 距离。

也就是说， 网络不直接回归位姿，而是先回答“物体的哪一部分被看到了”，把病态的回归换成一个形状选择问题。这个转换的好处是：可见性只在物体自身的规范空间里定义，与场景坐标无关，因此训练不需要场景级位姿标注。

观测编码

方法建立在 3DShape2VecSet 这类表示上：编码器用交叉注意力把点云聚合为 MMM 个 latent，解码器再用注意力在任意查询坐标上读出占据值。作者把两路输入分别编码：完整的 mesh 走冻结的预训练形状编码器，部分观测走结构相同、权重可训练的观测编码器，两者用同一套初始化。

冻结与可训练的分工不是随手定的。消融里把它换成“共享一个可训练编码器”，指标就掉了下来（GT 深度下 CD 从 0.34 升到 0.57）——说明如果让不完整、带噪的观测去更新编码器，mesh 先验会被带偏。

另一个细节是观测编码器去掉了 KL 正则瓶颈。原表示是为生成建模设计的，需要把形状压进一个平滑的隐空间；这里做的是条件重建，保留完整的 latent 容量更有利于保住细节，也避免把观测噪声和结构信息混在一起。

可见性场预测器

解码器原本是从 mesh latent 重建完整、封闭的表面。作者没有丢掉这个先验，而是让观测 latent 去调制它：在解码器每一层的自注意力之后插入一个交叉注意力，

M(l+1)=CrossAttn(SelfAttn(M(l)), O),M^{(l+1)}=\mathrm{CrossAttn}\left(\mathrm{SelfAttn}\left(M^{(l)}\right),\,O\right), M(l+1)=CrossAttn(SelfAttn(M(l)),O),

其中 mesh latent 作为 query，观测 latent 提供 key 和 value。这个方向是刻意选的非对称设计：mesh 保持主语地位，观测只是调节它。消融里把方向反过来（让观测当 query），CD 从 0.349 直接升到 1.905，说明 一旦让观测主导表示，mesh 先验就基本失效了。

最后一层投影做零初始化，于是训练开始时条件分支不引入任何扰动，模型的行为等同于原来的无条件网格解码器，训练能平稳起步。

可见性本身在 mesh 表面上采样查询点来解码：

再用 v^(x)>0.5\hat{v}(x)>0.5v^(x)>0.5 取出可见点集。也就是说，阈值化之后的那些点就是“如果从观测视角看，网格上应该被看到的部分”。

监督与数据合成

可见性没法直接标注，作者用渲染来自监督。对每个物体预渲染 60 个均匀采样的视角深度图，训练时随机取 1 到 3 个视角，按已知相机位姿把深度图反投影到 mesh 坐标系，得到与 mesh 对齐的部分点云，作为正样本。

构造网络输入时，再对这份点云施加一个随机相似变换：

P^obs={sRp+t∣p∈Paligned},\hat{P}_{\text{obs}}=\left\{sRp+t\mid p\in P_{\text{aligned}}\right\}, P^obs​={sRp+t∣p∈Paligned​},

s∈R+s\in\mathbb{R}^{+}s∈R+、R∈SO(3)R\in SO(3)R∈SO(3)、t∈R3t\in\mathbb{R}^{3}t∈R3 随机采样，随后归一化到单位球。因为真实的对应关系是构造出来的，网络可以在完全自监督的方式下学习：给它一个被随机摆放过的观测，让它把可见表面找回来。

负样本的采样规则是这篇里比较容易被忽略、但消融证明很重要的一步。可见点直接标 y=1y=1y=1；不可见点从整个 mesh 表面采样，但只有当它离所有可见点的距离都大于一个排除半径 rexclr_{\text{excl}}rexcl​ 时才被接受：

min⁡r∈R∥pinv−r∥2>rexcl.\min_{r\in R}\left\|p_{\text{inv}}-r\right\|_{2}>r_{\text{excl}}. r∈Rmin​∥pinv​−r∥2​>rexcl​.

可以想象一块正面被看到的桌板：它的边缘附近既有真正可见的部分，也有被遮挡的部分，两者在几何上只差几毫米。如果负样本均匀撒在表面上，网络就会在可见与不可见的边界上收到互相矛盾的监督，学出来的不是清晰的分界，而是一片模糊的过渡带。排除半径的作用就是在边界上留出一条缓冲带，让负样本明确落在“确实没被看到”的区域。消融里去掉它，CD 从 0.349 升到 0.520。

训练目标是这些查询点上的二元交叉熵。

实验

设定。 训练用 Objaverse 里筛出的 13 万个高质量 mesh，学习率 10−410^{-4}10−4，训练 3 万步。评测在 3D-FUTURE 上随机取 1000 个场景，消融用其中 250 个。指标是拼接所有物体表面点云后的 Chamfer Distance 与 F-score（阈值 0.05 与 0.10，每个物体 4096 点）。为避免全局尺度影响，作者用真值包围盒导出的同一个各向同性因子对两组点云做归一化，之后不做任何 ICP 或逐物体配准，所以平移、旋转、尺度、布局的错误都完整暴露在指标里。

对比。 基线包括：在场景里直接生成的 3DFixer、规范空间生成加布局回归的 SAM3D、在 SAM3D 基础上做渲染与配准精修的 SAM3D+PO，以及用 SAM3D 物体做参考形状的 Any6D。结果（表中数值已乘 100，CD 越小越好、F 越大越好）：

两个现象值得说。其一，姿态精修反而变差：SAM3D+PO 在 SAM3D 的基础上把 F@0.05 从 75.01 拉低到 74.26。作者给了两条理由——基于渲染的对齐本身有尺度歧义（大而远的物体与小而近的物体可以渲染出几乎一样的图），以及用完整 mesh 去对部分观测会系统性偏向没有观测到的区域。这两条其实正好说明了为什么“先选出可见表面再配准”是必要的。其二，深度换成估计值之后差距拉大：Any6D 的 CD 从 1.04 涨到 2.87，而本文从 0.36 到 0.77；作者的训练里也没有用估计深度做增广，所以这个鲁棒性不是靠数据对齐换来的。

消融（GT 深度）：共享编码器 CD 0.57、反转注意力方向 1.90、去掉排除半径 0.52，完整设置 0.34。三个设计各自都有明确的作用，其中注意力方向的影响最大。

核心点和不足

值得关注

这篇最漂亮的地方是换了一个被预测的量。位姿回归难，是因为它在数值上病态；可见性预测相对容易，因为它是一个有几何意义的二分类问题，而且监督可以从渲染里免费拿到。一旦可见表面被找出来，剩下的配准就是经典问题。 把“估计变换”改成“选择表面”，相当于把病态问题换成了良态问题。

配套的两个设计也服务于同一件事：冻结 mesh 编码器、让观测只做调制，是在保护生成模型的规范空间先验；排除半径是在保护可见/不可见的边界。两者都不是锦上添花，消融里拿掉任何一个都会明显掉点。

因为它完全在物体级数据上训练、不依赖场景级位姿标注，也不改生成流水线，这套模块可以插到不同的生成器后面——论文里换了真值物体、估计深度、室外场景、卡通风格、多视角输入，都还能用。

仍然存在的问题

首先是尺度的处理没有讲透。训练时对观测施加的是含尺度的相似变换（式中的 sss），但方法一节和结论里反复说的是求解“刚体变换”，而评测又用真值包围盒的尺度做了全局归一化。这三处对尺度的处理并不一致：如果 TTT 真是刚体变换，生成 mesh 在 [−1,1]3[-1,1]^{3}[−1,1]3、观测在米制场景里，尺度对不上；如果实际解的是相似变换，论文又没有明说尺度从哪里来。对想复现的人，这是一个必须先问清楚的点，也直接影响“物体大小”这类下游量是否可信。

其次是可见性场依赖生成网格与观测在可见区域上对得上。如果生成物体在结构上偏离观测（比如把一把椅子生成成了另一种靠背），可见表面即使预测得“自洽”，配准到的也是错的对应。论文的动机里承认生成物“可能只是结构或功能相似”，但方法本身没有机制去检测这种不一致。

第三是对称与重复结构。可见性场本身不含朝向信息，对于一个前后近似对称的物体，可见表面可能对应多个合理的刚体变换，Chamfer 距离在这些解之间可能区分不开。论文没有讨论对称性，也没有给出多解时的选择策略。

第四是流程是逐物体、单帧的。每个物体独立求解，物体之间的相互遮挡、支撑关系（杯子在桌上、书在书架里）都没有显式建模；输入也只考虑静态的单帧或多视角重建。组合场景里真正难的“物体之间是否物理合理”，仍然留给上游或下游。

最后，评测口径偏乐观。用真值包围盒的尺度做全局归一化，会把逐物体的尺度误差部分吸收掉；F-score 的阈值 0.05/0.10 也是相对归一化后的点云而言。指标本身没问题，但读的时候要记住它衡量的是“归一化后的布局精度”，不等于米制场景里的绝对误差。

总结

ScenePlacer 的流程可以归纳为三步：

  • 用冻结的形状编码器和可训练的观测编码器，分别把生成 mesh 与观测点云编码成 latent；
  • 让观测 latent 通过交叉注意力调制 mesh 解码器，在 mesh 表面逐点预测“是否可见”，阈值化得到可见表面；
  • 用 Chamfer 距离把可见表面与观测点云对齐，解出把生成物体放回场景的变换。

训练完全在物体级数据上自监督完成：渲染 60 个视角的深度图，随机取几帧反投影成部分点云，再施加随机相似变换，让网络学会“给定一个被摆歪的观测，把它在 mesh 上的可见区域找回来”。

它给出的启示是： 组合式场景生成里，位姿问题未必需要更好的位姿回归器，可能只需要一个更好的中间量。沿着这条线，下一步值得看的是尺度如何被显式恢复（而不是被评测归一化吸收），以及可见性场能否扩展到多物体、带支撑关系的联合摆放。
